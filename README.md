# 🎮 รวมเกมการศึกษา (Game Hub)

เว็บไซต์เดียวที่รวมลิงก์เกมการศึกษาจาก Google Apps Script ไว้ในที่เดียว
แบ่งหมวดหมู่ตาม **วิชา** และ **ระดับชั้น** นักเรียนเปิดจากมือถือ กดการ์ดเพื่อเล่นได้เลย

เป็นเว็บ static ล้วน (HTML/CSS/JS) ไม่มี build step — เปิดไฟล์ `index.html` ตรงๆ ก็ทำงาน

---

## ➕ วิธีเพิ่ม / แก้เกม

มี 2 วิธี:

### วิธี A — หน้าจัดการในเว็บ (แนะนำ ไม่ต้องแตะโค้ด)

เปิด **`/admin.html`** (ลิงก์ “⚙️ จัดการเกม (สำหรับครู)” อยู่ท้ายหน้าเว็บ)

1. **ขั้นที่ 1 ครั้งเดียว** — สร้าง GitHub *fine-grained token* (สิทธิ์ **Contents: Read and write** เฉพาะ repo นี้) วางในช่อง แล้วกด “ทดสอบการเชื่อมต่อ”
   - token เก็บใน **sessionStorage** ของแท็บนั้นเท่านั้น (หายเองเมื่อปิดแท็บ) ไม่ถูกอัปโหลด นักเรียนไม่ต้องมี
2. กรอกฟอร์มเพิ่มเกม / กด ✏️ แก้ / 🗑️ ลบ / ↑↓ จัดลำดับ ในรายการ
3. กด **“บันทึกขึ้นเว็บ (commit)”** — ระบบจะ commit `games.js` เข้า repo ให้ GitHub Actions deploy ใหม่อัตโนมัติ **นักเรียนเห็นภายใน ~1 นาที**

> ⚠️ อย่าใช้หน้า admin บนเครื่องสาธารณะ และกด “ลืม token เครื่องนี้” เมื่อใช้เสร็จบนเครื่องที่ไม่ใช่ของตัวเอง

### วิธี B — แก้ไฟล์ `games.js` มือ

แก้ไฟล์ **`games.js`** ไฟล์เดียวเท่านั้น ก๊อปปี้บล็อกเกมเดิม วางต่อ แล้วแก้ข้อมูล:

```js
{
  id: "math-speed",                    // รหัสคงที่ (ลิงก์แชร์อ้างจากนี่ — ห้ามเปลี่ยนหลังเผยแพร่)
  title: "เกมคิดเลขเร็ว",              // ชื่อเกม
  description: "ฝึกบวกลบใน 60 วินาที",   // คำอธิบายสั้นๆ
  subject: "คณิตศาสตร์",                // วิชา (พิมพ์อะไรก็ได้)
  grades: ["ป.4", "ป.5"],              // ระดับชั้น ใส่ได้หลายชั้น
  url: "https://script.google.com/macros/s/XXXX/exec",  // ลิงก์เกม
  emoji: "🔢",                         // (ไม่ใส่ก็ได้) ไอคอนบนการ์ด
  color: "#4f8ef7",                    // (ไม่ใส่ก็ได้) สีธีมการ์ด
},
```

- **`id` ต้องไม่ซ้ำและไม่เป็นเลขล้วน** — ลิงก์แชร์เกมใช้ `#game=<id>` เพื่อให้เรียง/ลบเกมแล้วลิงก์เดิมยังเปิดเกมเดิม (หน้า admin สร้าง id ให้อัตโนมัติเมื่อเพิ่มเกมใหม่)
- **ปุ่มกรองวิชาและระดับชั้นสร้างให้อัตโนมัติ** จากค่าที่มีจริงในไฟล์ ไม่ต้องแก้ที่อื่น
- ใช้รูปแบบระดับชั้น `ป.1`–`ป.6`, `ม.1`–`ม.6` เพื่อให้เรียงลำดับถูก
- ⚠️ อย่าลืมเครื่องหมายจุลภาค `,` คั่นแต่ละบล็อก

## 🖼️ ทำให้เกมแสดงในกรอบพรีวิว (iframe)

เมื่อกดการ์ด เว็บจะเปิดพรีวิวเกมในกรอบ iframe ให้ **เกม Google Apps Script จะแสดงในกรอบได้ก็ต่อเมื่อตอน deploy ตั้งค่าดังนี้:**

1. ในโค้ด GAS ให้ `doGet` คืน `HtmlOutput` ที่อนุญาต iframe:
   ```js
   function doGet() {
     return HtmlService.createHtmlOutputFromFile('index')
       .setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL);
   }
   ```
2. ตอน **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
3. ใช้ URL ที่ลงท้ายด้วย `/exec` (ไม่ใช่ `/dev`)

> ถ้าเกมไหนไม่ได้ตั้ง `ALLOWALL` กรอบพรีวิวจะว่าง — ผู้เล่นยังกดปุ่ม **"เปิดในแท็บใหม่"** เพื่อเล่นเต็มหน้าจอได้เสมอ (และถ้าโหลดเกิน 9 วินาที เว็บจะขึ้นปุ่มทางออกให้อัตโนมัติ)

## 🚀 เปิดใช้งานบน GitHub Pages

เว็บนี้ deploy อัตโนมัติด้วย **GitHub Actions** (`.github/workflows/deploy-pages.yml`) —
ทุกครั้งที่ push เข้า `main` (หรือกด “บันทึกขึ้นเว็บ” ในหน้า admin) เว็บจะอัปเดตเองภายใน ~1 นาที
ที่ `https://<username>.github.io/allgamespnp/` โดยไม่ต้องตั้งค่า Pages ซ้ำ

## 📁 โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|------|---------|
| `index.html` | โครงหน้าเว็บนักเรียน |
| `games.js` | **ข้อมูลเกม** (แต่ละเกมมี `id` คงที่สำหรับลิงก์แชร์) |
| `announcement.js` | ข้อความประกาศหน้าเว็บ |

| `admin.html` / `admin.js` / `admin.css` | หน้าจัดการเกม+ประกาศสำหรับครู |
| `.github/workflows/deploy-pages.yml` | deploy ขึ้น Pages อัตโนมัติ |

## ✨ ฟีเจอร์

- 🔍 ค้นหาชื่อเกม + กรองวิชาและระดับชั้นพร้อมกัน (ค่าถูกจำใน URL — รีเฟรช/แชร์ผลลัพธ์ได้)
- 📱 รองรับมือถือเต็มรูปแบบ + โหมดมืดอัตโนมัติ
- ♿ เข้าถึงด้วยคีย์บอร์ด: โมดัลย้าย focus/กัก focus/คืน focus, กด Back ปิดได้, จุดกด ≥ 44px, contrast ผ่าน WCAG AA
- 🎬 พรีวิวเกมในกรอบ + timeout/ปุ่มทางออก + เปิดในแท็บใหม่ + คัดลอกลิงก์
- 🔗 แชร์ลิงก์เกมเดียวด้วย `#game=<id>` (เรียง/ลบเกมแล้วลิงก์เดิมยังเปิดเกมเดิม)
- 📢 ประกาศหน้าเว็บ (แถบด้านบน หรือเด้งกลางจอสำหรับเรื่องสำคัญ)
- 📺 **โหมดครูฉายจอ** — ปุ่มในแถบผลลัพธ์ หรือเปิดตรงด้วย `?present=1` ตัวอักษร/การ์ดใหญ่ขึ้นสำหรับฉายหน้าห้อง (bookmark ไว้ที่เครื่องฉายได้)
- ⚙️ หน้าจัดการสำหรับครู: เพิ่ม/แก้/ลบ/เรียง, ค้นหาในรายการ, เลิกทำหลังลบ, กันเขียนทับ, เตือนงานที่ยังไม่บันทึก
- 🕘 **ประวัติการแก้ไข + กู้คืน** — ดู commit ล่าสุดของ `games.js` ในหน้า admin แล้วย้อนกลับไปเวอร์ชันเก่าได้ (กู้คืนแล้วยังไม่ขึ้นเว็บจนกว่าจะกด “บันทึกขึ้นเว็บ” จึงตรวจด้วยปุ่มดูตัวอย่างก่อนได้)
- 💾 **สำรอง/กู้คืนเป็นไฟล์** — ดาวน์โหลดไฟล์สำรองพร้อมวันที่ แล้วกู้คืนโดยเลือกไฟล์ตรงๆ ไม่ต้อง copy-paste

### แนวทางเนื้อหา (สำหรับครู)
- **คำอธิบายเกม** ~40–80 ตัวอักษร บอกว่า “เรียนเรื่องอะไร” เพื่อให้นักเรียนแยกเกมออก
- **`id` ของเกม** ห้ามเปลี่ยนหลังเผยแพร่ (หน้า admin สร้างให้อัตโนมัติเมื่อเพิ่มเกมใหม่)

## 🧪 การทดสอบ (สำหรับผู้ดูแลโค้ด)

มี smoke test + accessibility test ด้วย Playwright — รันทุก push/PR ผ่าน GitHub Actions (`.github/workflows/ci.yml`)

```bash
npm install                 # ครั้งแรก
npx playwright install chromium
npm test                    # รัน tests/ ทั้ง desktop + mobile (รวม axe a11y)
```

- `tests/hub.spec.js` — แสดงเกม, ค้นหา/กรอง, โมดัล (click/Escape/Back), deep link, บั๊ก dialog stack
- `tests/admin.spec.js` — validation, เพิ่มเกม, ค้นหาในรายการ, undo, token sessionStorage, import schema
- `tests/projection.spec.js` — โหมดครูฉายจอ (ตัวอักษรใหญ่ขึ้นจริง, จำใน URL, ล้างตัวกรองแล้วไม่หลุด)
- `tests/history.spec.js` — ประวัติการแก้ไข/กู้คืนเวอร์ชัน (รวมกรณีสำคัญ: กู้คืนแล้ว commit ต้องใช้ sha ของ HEAD) + กู้คืนจากไฟล์
- `tests/a11y.spec.js` — axe WCAG 2 A/AA (ไม่มี violation ระดับ critical/serious)
- `npm run test:links` — ตรวจว่าลิงก์เกมทุกเกมยังเปิดได้ (มี workflow ตั้งเวลารายสัปดาห์)
