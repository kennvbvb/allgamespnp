⚙️ จัดการเกม

เพิ่ม/แก้/ลบเกม แล้วกด “บันทึกขึ้นเว็บ” นักเรียนทุกคนจะเห็นภายใน ~1 นาที

← กลับหน้าเว็บเกม

1. เชื่อมต่อ GitHub (ทำครั้งเดียว เครื่องนี้จำให้)

กำลังตรวจสอบสถานะการล็อกอิน…

วิธีสร้าง Token (กดดู)
  1. เปิด github.com/settings/personal-access-tokens/new (Fine-grained token)
  2. Repository access → Only select repositories → เลือก allgamespnp
  3. Permissions → Repository permissions → Contents → เลือก Read and write
  4. กด Generate token แล้วคัดลอกมาวางในช่องด้านล่าง

⚠️ Token เก็บไว้ในแท็บนี้เท่านั้น (หายเมื่อปิดแท็บ) ไม่ถูกอัปโหลดขึ้นเว็บ และนักเรียนไม่ต้องมี — แนะนำตั้ง PAT อายุสั้นและจำกัดเฉพาะ repo นี้ + Contents:write

⚙️ ตั้งค่าขั้นสูง (ปกติไม่ต้องแตะ)

2. เพิ่มเกมใหม่

ระดับชั้น * (เลือกได้หลายชั้น)

รายละเอียดเพิ่มเติม (ไม่บังคับ) — หัวข้อย่อย, เวลาเล่น, โหมด, ป้าย, รูปปก

3. รายการเกม 0 ● ยังไม่เผยแพร่

กำลังโหลดข้อมูลปัจจุบัน…

    ไม่พบเกมที่ตรงกับการค้นหา

    เลือกไว้ 0 เกม

    สำรอง/กู้คืนข้อมูล (JSON)

    เลือกไฟล์แล้วระบบจะถามยืนยันก่อนแทนที่รายการ — ยังไม่ขึ้นเว็บจนกว่าจะกด “บันทึกขึ้นเว็บ”

    ประวัติการแก้ไข (ย้อนกลับได้)

    รายการบันทึกล่าสุดของไฟล์เกม — กดกู้คืนแล้วรายการจะกลับไปเป็นเวอร์ชันนั้น แต่ยังไม่ขึ้นเว็บจนกว่าจะกด “บันทึกขึ้นเว็บ”

      4. ประกาศหน้าเว็บ (ป๊อปอัปตอนนักเรียนเข้าเว็บ)

      ● มีการแก้ไขที่ยังไม่เผยแพร่
