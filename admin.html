1. เชื่อมต่อ GitHub (ทำครั้งเดียว เครื่องนี้จำให้)

วิธีสร้าง Token (กดดู)
  1. เปิด github.com/settings/personal-access-tokens/new (Fine-grained token)
  2. Repository access → Only select repositories → เลือก allgamespnp
  3. Permissions → Repository permissions → Contents → เลือก Read and write
  4. กด Generate token แล้วคัดลอกมาวางในช่องด้านล่าง

⚠️ Token นี้เก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ถูกอัปโหลดขึ้นเว็บ และนักเรียนไม่ต้องมี — อย่าใช้บนเครื่องสาธารณะ
